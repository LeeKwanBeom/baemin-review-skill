## 로깅 규칙 (전 단계 공통)

모든 단계에서 아래 접두사로 진행 상황을 채팅에 출력한다.
- `[STEP N]` — 단계 시작
- `[OK]` — 성공
- `[WARN]` — 비중요 경고 (계속 진행)

### 4-A: API 직접 호출 (1순위)

#### 4-A-1. fetch 호출 (10초 타임아웃 + 상세 에러 로그)

```javascript
const shopId = '<SHOP_ID>';
const today = new Date();
const from  = new Date(today);
from.setDate(today.getDate() - 6);
const toStr   = today.toISOString().slice(0, 10);
const fromStr = from.toISOString().slice(0, 10);

let _apiResult;
let all = [], offset = 0;
const limit = 100;

try {
  outer: while (true) {
    const url = `https://self-api.baemin.com/v1/review/shops/${shopId}/reviews` +
                `?from=${fromStr}&to=${toStr}&offset=${offset}&limit=${limit}`;

    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), 3000);  // 3초 — CSP 차단 시 즉시 에러, 실 타임아웃도 3초면 충분

    let r;
    try {
      r = await fetch(url, { credentials: 'include', signal: controller.signal });
    } finally {
      clearTimeout(timer);
    }

    if (!r.ok) {
      const body = await r.text().catch(() => '(body read failed)');
      _apiResult = { error: r.status, stage: 'fetch_response', body: body.substring(0, 200), fromDate: fromStr, toDate: toStr };
      break;
    }

    const d = await r.json();
    // 필드명 fallback 체인
    const items = d.reviews ?? d.data ?? d.content ?? d.list ?? (Array.isArray(d) ? d : null);
    if (!Array.isArray(items)) {
      _apiResult = { error: 'unknown_shape', stage: 'parse_response', keys: Object.keys(d).slice(0, 10), fromDate: fromStr, toDate: toStr };
      break;
    }
    if (items.length === 0) break;
    all = all.concat(items);
    if (items.length < limit) break;
    offset += limit;
  }
  if (!_apiResult) _apiResult = { total: all.length, fromDate: fromStr, toDate: toStr, reviews: all };
} catch (e) {
  _apiResult = { error: e.name === 'AbortError' ? 'timeout_10s' : e.message, stage: 'fetch_call', fromDate: fromStr, toDate: toStr };
}
JSON.stringify(_apiResult)
```

#### 4-A-3. 리뷰 파싱 (API 성공 시)

각 리뷰 객체에서 필드를 아래 우선순위로 추출한다.
Python으로 파싱할 때 아래 함수를 사용:

```python
def extract_field(r, *keys, default=''):
    """중첩 키 포함 fallback 체인. 예: extract_field(r, 'writer.nickname', 'nickname')"""
    for key in keys:
        parts = key.split('.')
        val = r
        for p in parts:
            if isinstance(val, dict):
                val = val.get(p)
            else:
                val = None
                break
        if val is not None and str(val).strip():
            return val
    return default

def parse_review_api(r):
    stars_raw = extract_field(r, 'starRating', 'reviewStar', 'score', 'star', 'rating', default=-1)
    try:
        stars = int(stars_raw)
    except:
        stars = -1

    date_raw = extract_field(r, 'reviewDate', 'createdAt', 'date', 'orderDate', 'registeredAt')
    date_str = iso_to_korean(date_raw)

    review_no = str(extract_field(r, 'reviewId', 'id', 'reviewNo', 'no', default=''))
    nickname  = extract_field(r, 'writer.nickname', 'nickname', 'writerNickname', 'customerNickname')
    menu      = extract_field(r, 'orderedMenuName', 'menuName', 'menus', default='')
    if isinstance(menu, list):
        menu = ', '.join(str(m.get('name', m)) for m in menu)
    content   = extract_field(r, 'reviewContents', 'content', 'comment', 'reviewText', 'text', default='(텍스트 없음)')

    return {'stars': stars, 'date': date_str, 'reviewNo': review_no,
            'nickname': nickname, 'menu': str(menu), 'reviewText': str(content)}
```

ISO 날짜 변환:
```python
import re
def iso_to_korean(s):
    s = str(s or '').strip()
    # 이미 한국어 날짜면 그대로 반환
    if '년' in s and '월' in s:
        return s
    # YYYY-MM-DD 패턴을 정규식으로 직접 추출
    # +09:00, Z, T00:00:00 등 뒤에 무엇이 붙어도 정상 동작
    m = re.search(r'(\d{4})-(\d{1,2})-(\d{1,2})', s)
    if m:
        return f"{m.group(1)}년 {int(m.group(2))}월 {int(m.group(3))}일"
    return s[:10] if len(s) >= 10 else s
```

#### 4-B-1. 날짜 필터 "최근 7일" 변경

**1단계: JS로 직접 클릭 시도**

먼저 JS로 버튼 텍스트를 찾아 클릭한다. JS 클릭이 실패하면 `find()` + ref 클릭으로 fallback한다.

```javascript
// 시도 1: 현재 날짜 필터 상태 텍스트('최근 N개월/N일')로 버튼 탐색
// button, [role="button"] 만 사용 — div[class*="filter"] 등 클래스 기반 셀렉터는 해시화로 깨짐
const _patterns = ['최근 6개월', '최근 7일', '최근 30일', '최근 3개월', '기간 선택', '기간', '날짜', '조회기간'];
let _filterClicked = false;
for (const pat of _patterns) {
  const el = [...document.querySelectorAll('button, [role="button"]')]
    .find(e => e.innerText?.includes(pat) && e.offsetParent !== null);
  if (el) { el.click(); _filterClicked = pat; break; }
}
_filterClicked ? `clicked: ${_filterClicked}` : 'not_found'
```

- `'not_found'`이면 → **시도 2: 날짜 범위 텍스트 역추적**으로 fallback:

```javascript
// 시도 2: 현재 표시된 날짜 범위 텍스트로 버튼 역추적
// (텍스트 라벨보다 날짜 형식이 변경될 가능성이 낮음)
(() => {
  const els = [...document.querySelectorAll('button, [role="button"], div, span')]
    .filter(el =>
      /\d{4}\.\s*\d{1,2}\.\s*\d{1,2}.*~/.test(el.innerText?.trim()) &&
```

#### 4-B-2. Virtual Scroll로 전체 리뷰 수집

배민 리뷰 목록은 virtual scroll 방식이라 DOM에는 화면에 보이는 약 6개만 유지된다.
80ms 간격 스크롤 + 15,000px 청크 분할로 타임아웃을 방지한다.

**헬퍼 함수 초기화 (매장마다 최초 1회 실행)**

```javascript
window._allReviews = {};
window._reviewLog  = [];  // 파싱 이벤트 로그

window._collectVisible = function() {
  // ── 카드 탐색 전략 ──────────────────────────────────────────────────
  // span.innerText 기반 탐색
  // 배민 DOM은 <span> 안에 "리뷰번호" 텍스트노드 + 번호 텍스트노드가 분리되어 있어
  // TreeWalker로 텍스트노드를 탐색하면 매칭 실패함 → span.innerText로 탐색
  // 1차: "리뷰번호 XXXXXX" 텍스트 라벨로 탐색
  let reviewSpans = [...document.querySelectorAll('span')]
    .filter(s => /^리뷰번호\s+\d+$/.test(s.innerText?.trim()));

  // 2차 fallback: 라벨 변경/제거 시 20으로 시작하는 16자리 숫자로 탐색
  if (reviewSpans.length === 0) {
    reviewSpans = [...document.querySelectorAll('span')]
      .filter(s => /^20\d{14}$/.test(s.innerText?.trim()));
  }

  for (const span of reviewSpans) {
    const rawText = span.innerText.trim();
    const noMatch = rawText.match(/리뷰번호\s+(\d+)/) || rawText.match(/^(20\d{14})$/);
    if (!noMatch || window._allReviews[noMatch[1]]) continue;

    // ── 카드 루트 탐색: 주문메뉴가 포함된 컨테이너까지 탐색 ──────────
    // 파트너 전용 리뷰·메뉴 영역을 포함하려면 충분히 넓은 상위 컨테이너가 필요
    let card = null;

    // 시도 1: 시맨틱 태그 / aria role 우선 (클래스명 해시화에 무관)
    // li, article, [role="listitem"], [role="article"] 는 접근성 요구상 잘 바뀌지 않음
    // 추가 조건: 주문메뉴 텍스트 포함 여부로 올바른 카드 경계 검증
    const semanticSelectors = [
      'li', 'article',
      '[role="listitem"]', '[role="article"]'
    ];
    for (const sel of semanticSelectors) {
      const found = span.closest(sel);
      if (found && found.innerText?.includes('주문메뉴')) { card = found; break; }
    }

    // 시도 2: CSS 클래스 패턴 (시맨틱 실패 시 fallback — 클래스명 미해시화 환경 대응)
    if (!card) {
      const classSelectors = [
        '[class*="review-item"]', '[class*="ReviewItem"]',
        '[class*="review_item"]', '[class*="reviewCard"]',
        '[class*="review-card"]', '[class*="ReviewCard"]',
        'li[class*="review"]', 'article[class*="review"]'
      ];
      for (const sel of classSelectors) {
        const found = span.closest(sel);
        if (found) { card = found; break; }
      }
      // 클래스로 찾았지만 주문메뉴 미포함이면 상위로 확장 (최대 10단계)
      if (card && !card.innerText?.includes('주문메뉴')) {
        let el = card;
        for (let i = 0; i < 10; i++) {
          el = el?.parentElement;
          if (!el) break;
          if (el.innerText?.includes('주문메뉴')) { card = el; break; }
        }
      }
    }

    // 시도 3: 부모 텍스트 탐색 — 주문메뉴 포함 컨테이너 직접 탐색 (최대 20단계)
    if (!card) {
      let el = span;
      for (let i = 0; i < 20; i++) {
        el = el?.parentElement;
        if (!el) break;
        if (el.innerText?.includes('주문메뉴')) { card = el; break; }
      }
    }

    // 최후 fallback: 주문메뉴 미발견 시 10단계 부모
    if (!card) {
      card = span;
      for (let i = 0; i < 10; i++) card = card?.parentElement;
    }

    if (!card) {
      window._reviewLog.push(`[WARN] card_not_found reviewNo=${noMatch[1]}`);
      continue;
    }

    const text = card.innerText || '';

    // ── 별점 파싱: 4단계 전략 ──────────────────────────────────────
    let yellowCount = -1;
    const svgs = [...card.querySelectorAll('svg')];

    // 전략 1: aria-label에 "N점" 패턴
    for (const svg of svgs) {
      const aria = svg.getAttribute('aria-label') || svg.closest('[aria-label]')?.getAttribute('aria-label') || '';
      const m = aria.match(/(\d)점/);
      if (m) { yellowCount = parseInt(m[1]); break; }
    }

    // 전략 2: data-rating / data-score 속성
    if (yellowCount === -1) {
      const rated = card.querySelector('[data-rating],[data-score],[data-star]');
      if (rated) {
        const v = rated.getAttribute('data-rating') || rated.getAttribute('data-score') || rated.getAttribute('data-star');
        const n = parseInt(v);
        if (!isNaN(n) && n >= 1 && n <= 5) yellowCount = n;
      }
    }

    // 전략 3: SVG fill 색상 — hex 직접 비교 + RGB 범위 조건 (r>180 && g>130 && b<80)
    // 특정 hex값 하드코딩 대신 RGB 범위로 노란 계열 전체를 포괄 (배민 색상 변경에 강건)
    if (yellowCount === -1) {
      let cnt = 0;
      for (const svg of svgs) {
        const paths = [...svg.querySelectorAll('path, polygon, circle, rect')];
        for (const p of paths) {
          const attrFill     = (p.getAttribute('fill') || '').toUpperCase();
          const styleFill    = (p.style?.fill || '').toUpperCase();
          const computedFill = getComputedStyle(p).fill || '';
          // hex 직접 매칭 (attrFill/styleFill)
          const hexYellow =
            attrFill.includes('FFC600') || attrFill.includes('FFB800') || attrFill.includes('FFCC00') ||
            attrFill.includes('FFCA28') || attrFill.includes('FFD600') || attrFill.includes('FFB300') ||
            styleFill.includes('FFC600') || styleFill.includes('FFB800') || styleFill.includes('FFCC00') ||
            styleFill.includes('FFCA28') || styleFill.includes('FFD600') || styleFill.includes('FFB300');
          // computed RGB 범위 조건: 노란 계열 (r>180 && g>130 && b<80)
          const rgbM = computedFill.match(/rgba?\((\d+),\s*(\d+),\s*(\d+)/);
          const rgbYellow = rgbM
            ? (parseInt(rgbM[1]) > 180 && parseInt(rgbM[2]) > 130 && parseInt(rgbM[3]) < 80)
            : false;
          if (hexYellow || rgbYellow) { cnt++; break; }
        }
      }
      if (cnt > 0) yellowCount = cnt;
      else if (svgs.length >= 5) {
        yellowCount = -1; // 파싱 실패 플래그 — 전략 4 시도
      }
    }

    // 전략 4: 텍스트에서 "★N" 또는 "N점" 패턴
    if (yellowCount === -1) {
      const starTextM = text.match(/[★]{1,5}|(\d)점\s*\/\s*5점|별점[:\s]*(\d)/);
      if (starTextM) {
        if (starTextM[0].startsWith('★')) yellowCount = (starTextM[0].match(/★/g) || []).length;
        else if (starTextM[1]) yellowCount = parseInt(starTextM[1]);
        else if (starTextM[2]) yellowCount = parseInt(starTextM[2]);
      }
    }

    // 전략 4 후에도 -1이면 → 실제 파싱 실패로 확정
    if (yellowCount === -1) {
      window._reviewLog.push(`[WARN] star_parse_fail reviewNo=${noMatch[1]} svgCount=${svgs.length}`);
    }

    // ── 날짜 파싱 ──────────────────────────────────────────────────
    const dateMatch = text.match(/(\d{4}년\s*\d{1,2}월\s*\d{1,2}일)/);
    const dateStr   = dateMatch?.[1] || '';

    // ── 닉네임 파싱: 3단계 fallback ────────────────────────────────
    // 배민 DOM 실제 구조: [배달타입] [닉네임] [날짜] [리뷰번호] [N회 주문 고객] [(최근 6개월 누적 주문)] ...
    // ※ "N회 주문 고객" 패턴 때문에 includes('주문 고객') 사용 시 오탐 → 전략 전면 개편
    const lines = text.split('\n').map(l => l.trim()).filter(l => l);
    let nickname = '';
    const deliveryTypes = ['가게배달', '한집배달', '알뜰배달', '배달', '포장', '직접배달', '배민배달', '가게포장'];
    // 닉네임 유효성: 시스템 텍스트·배달 타입·특수 패턴 제외
    const isValidNickname = (n) =>
      n && n.length > 0 && n.length < 30 &&
      !n.startsWith('(') &&
      !/주문|리뷰번호|배달리뷰|답글|사장님/.test(n) &&
      !deliveryTypes.includes(n.trim());

    // 전략 1: 배달 타입 완전 일치 다음 줄 (가장 신뢰성 높음)
    // 배민 DOM: 배달타입 바로 다음 줄이 항상 닉네임
    const dIdx = lines.findIndex(l => deliveryTypes.some(t => l.trim() === t));
    if (dIdx >= 0 && dIdx + 1 < lines.length) {
      const candidate = lines[dIdx + 1];
      if (isValidNickname(candidate)) nickname = candidate;
    }

    // 전략 2: 날짜 바로 앞 줄 (배달 타입 미발견 또는 유효하지 않은 경우)
    if (!nickname && dateStr) {
      const dLineIdx = lines.findIndex(l => l.includes(dateStr.split('년')[0]));
      if (dLineIdx > 0) {
        const candidate = lines[dLineIdx - 1];
        if (isValidNickname(candidate)) nickname = candidate;
      }
    }

    // 전략 3: "주문 고객" 완전 일치 앞 줄
    // "N회 주문 고객" 오탐 방지: === 완전 일치만 사용, 닉네임은 레이블 앞 줄에 위치
    if (!nickname) {
      const cIdx = lines.findIndex(l => l === '주문 고객');
      if (cIdx > 0) {
        const candidate = lines[cIdx - 1];
        if (isValidNickname(candidate)) nickname = candidate;
      }
    }

    // ── 주문메뉴 파싱 ────────────────────────────────────────────
    const menuPatterns = [/주문메뉴\s*\n?\s*([^\n]+)/, /메뉴[:\s]+([^\n]+)/];
    let menu = '';
    for (const pat of menuPatterns) {
      const m = text.match(pat);
      if (m) { menu = m[1].trim(); break; }
    }

    // ── 리뷰 내용 파싱 (공개 + 파트너 전용) ───────────────────────
    const menuStart = text.indexOf('주문메뉴');
    const dateIdx2  = dateStr ? text.indexOf(dateStr) : -1;
    let publicText  = '';
    let partnerText = '';

    // 파트너 전용 리뷰 키워드 목록
    const partnerKeywords = ['사장님께만 보이는', '파트너에게만', '비공개 리뷰', '점주에게만'];

    // 공개 리뷰: 날짜 ~ 주문메뉴 사이 텍스트 (파트너 키워드 줄 제외)
    if (menuStart > 0 && dateIdx2 >= 0) {
      const rawC = text.substring(dateIdx2, menuStart);
      const contentLines = rawC.split('\n').map(l => l.trim()).filter(l =>
        l && !l.match(/^\d{4}년/) && !l.includes('리뷰번호') &&
        !l.includes('주문 고객') && !l.includes('누적 주문') &&
        !deliveryTypes.some(t => l.includes(t)) &&
        !partnerKeywords.some(kw => l.includes(kw))
      );
      if (contentLines.length > 0) publicText = contentLines.join(' ').trim();
    }

    // 파트너 전용 리뷰: 키워드 이후 ~ 다음 섹션(주문메뉴·배달리뷰·답글) 전까지
    for (const kw of partnerKeywords) {
      const kwIdx = text.indexOf(kw);
      if (kwIdx >= 0) {
        const afterKw = text.substring(kwIdx + kw.length);
        const stopPatterns = ['주문메뉴', '배달리뷰', '답글'];
        let stopIdx = afterKw.length;
        for (const stop of stopPatterns) {
          const si = afterKw.indexOf(stop);
          if (si >= 0 && si < stopIdx) stopIdx = si;
        }
        const partnerLines = afterKw.substring(0, stopIdx)
          .split('\n').map(l => l.trim())
          .filter(l => l && l.length > 1);
        if (partnerLines.length > 0) {
          partnerText = partnerLines.slice(0, 5).join(' ').trim();
          break;
        }
      }
    }

    // 최종 조합
    let reviewText = '(텍스트 없음)';
    if (publicText && partnerText) {
      reviewText = `${publicText} / [파트너전용] ${partnerText}`;
    } else if (publicText) {
      reviewText = publicText;
    } else if (partnerText) {
      reviewText = `[파트너전용] ${partnerText}`;
    }

    window._allReviews[noMatch[1]] = {
      reviewNo: noMatch[1], stars: yellowCount,
      date: dateStr, nickname, menu, reviewText
    };
  }
  return Object.keys(window._allReviews).length;
};
```

**스크롤 수집 — scrollTo(bottom) + scroll 이벤트 + 적응형 대기**

매 호출마다 페이지 맨 아래로 스크롤 후 DOM 안정화를 감지해 조기 종료한다.
`gained === 0` 또는 `newHeight === prevHeight`이면 수집 완료로 간주한다.
**각 호출은 1회씩만 실행** — IIFE async는 CDP에서 45초 타임아웃을 유발하므로 top-level await 사용.

```javascript
// 스크롤 1회 실행 — gained > 0이면 반복 호출, 0이면 중단
const _prevCount = Object.keys(window._allReviews).length;
const _prevHeight = document.body.scrollHeight;
// SPA에서 스크롤 컨테이너가 body가 아닌 내부 div일 경우를 위해 양쪽 모두 스크롤
const _sc = document.querySelector('[class*="ReviewList"], [class*="review-list"], [class*="reviewList"]')
          || document.querySelector('main') || null;
if (_sc) { _sc.scrollTop = _sc.scrollHeight; _sc.dispatchEvent(new Event('scroll', { bubbles: true })); }
window.scrollTo(0, document.body.scrollHeight);
window.dispatchEvent(new Event('scroll'));

// 적응형 대기: 100ms마다 scrollHeight 폴링, 300ms 안정화 시 조기 종료 (최대 2000ms)
let _stable = 0, _lastH = document.body.scrollHeight, _elapsed = 0;
while (_elapsed < 2000) {
  await new Promise(r => setTimeout(r, 100));
  _elapsed += 100;
  const _curH = document.body.scrollHeight;
  if (_curH === _lastH) { _stable += 100; if (_stable >= 300) break; }
  else { _stable = 0; _lastH = _curH; }
}
window._collectVisible();
const _newCount = Object.keys(window._allReviews).length;
JSON.stringify({
  prevCount: _prevCount,
  newCount: _newCount,
  gained: _newCount - _prevCount,
  prevHeight: _prevHeight,
  newHeight: document.body.scrollHeight,
  waitedMs: _elapsed
})
```

> **종료 조건**: `gained === 0` 또는 `newHeight === prevHeight`
> **최대 반복 횟수**: 30회 상한 — 스크롤 호출 횟수를 카운트해 30회 초과 시 `[WARN] 스크롤 루프 30회 초과 — 강제 종료` 출력 후 수집 완료 처리한다. (7일 리뷰 300건 이상이면 비정상 — 실질적 무한루프 방지)
> **대기 시간**: DOM 빠르면 ~400ms, 느리면 최대 2000ms (기존 고정 2000ms 대비 평균 50~70% 단축)

## Step 5: 엑셀 저장 (BytesIO 직접 저장 방식)

한글 파일명 처리 문제를 방지하기 위해 `io.BytesIO`로 저장 후 `open(path, 'wb')`로 직접 쓴다.

**시트 구조**: **"전체" 단일 시트**, 첫 번째 열은 **매장명**.
- 열 순서: 매장명 / 날짜 / 별점 / 리뷰번호 / 닉네임 / 주문메뉴 / 리뷰내용

### 5-1. JSON 저장 (ASCII 파일명 사용)

```bash
cat > /tmp/baemin_reviews.json << 'ENDJSON'
{"storeName": "<매장명>", "reviews": [여기에 파싱된 리뷰 배열]}
ENDJSON
```

리뷰 배열의 각 항목 형식:
```json
{"stars": 3, "date": "2026년 5월 31일", "reviewNo": "2026053112345678",
 "nickname": "홍길동", "menu": "1인 세트", "reviewText": "리뷰 내용"}
```

별점 파싱 실패 리뷰(`stars: -1`)는 `"reviewText"` 앞에 `"[별점확인필요] "` 접두사를 붙인다.

### 5-2. Python 저장 스크립트

날짜 정렬은 **오래된 날짜가 위(오름차순)**.
매장별 동기화: 배민에 없는 행만 삭제, 다른 매장 행은 유지.
저장 실패 시 `/tmp/`에 백업 저장 후 경고.

```bash
python3 - /tmp/baemin_reviews.json << 'ENDPY'
import io, openpyxl, os, glob, json, sys, re, traceback
from openpyxl.styles import Alignment, Font, PatternFill
from openpyxl.styles.numbers import FORMAT_TEXT

DATA_PATH = sys.argv[1]
with open(DATA_PATH, encoding='utf-8') as f:
    store = json.load(f)

store_name = store['storeName']
reviews    = store['reviews']

matches = glob.glob('/sessions/*/mnt/claude/배민_저점수리뷰.xlsx')
if matches:
    EXCEL_PATH = matches[0]
else:
    base = glob.glob('/sessions/*/mnt/claude')
    EXCEL_PATH = base[0] + '/배민_저점수리뷰.xlsx' if base else '/tmp/배민_저점수리뷰.xlsx'

def star_str(n):
    if n == -1: return '?점'
    return '★' * int(n) + '☆' * (5 - int(n))

def parse_date(d):
    m = re.match(r'(\d{4})년\s*(\d{1,2})월\s*(\d{1,2})일', str(d or ''))
    return (int(m.group(1)), int(m.group(2)), int(m.group(3))) if m else (0, 0, 0)

def make_header(ws):
    headers = ['매장명', '날짜', '별점', '리뷰번호', '닉네임', '주문메뉴', '리뷰내용']
    ws.append(headers)
    ws.row_dimensions[1].height = 20.0
    ws.column_dimensions['A'].width = 24.0
    ws.column_dimensions['B'].width = 18.0
    ws.column_dimensions['C'].width = 10.0
    ws.column_dimensions['D'].width = 20.0
    ws.column_dimensions['E'].width = 16.0
    ws.column_dimensions['F'].width = 36.0
    ws.column_dimensions['G'].width = 60.0
    hf = PatternFill(patternType='solid', fgColor='2F5496')
    for cell in ws[1]:
        cell.font      = Font(name='Arial', bold=True, color='FFFFFF')
        cell.fill      = hf
        cell.alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)

try:
    buf_in = io.BytesIO(open(EXCEL_PATH, 'rb').read())
    wb = openpyxl.load_workbook(buf_in)
    print(f'[OK] 기존 엑셀 로드: {EXCEL_PATH}', file=sys.stderr)
except FileNotFoundError:
    wb = openpyxl.Workbook()
    if 'Sheet' in wb.sheetnames:
        del wb['Sheet']
    print(f'[OK] 새 엑셀 생성', file=sys.stderr)
except Exception as e:
    print(f'[WARN] 엑셀 로드 실패 ({e}), 새 파일 생성', file=sys.stderr)
    wb = openpyxl.Workbook()
    if 'Sheet' in wb.sheetnames:
        del wb['Sheet']

data_align = Alignment(horizontal='center', vertical='center', wrap_text=True)

if '전체' in wb.sheetnames:
    ws = wb['전체']
else:
    ws = wb.create_sheet(title='전체')
    make_header(ws)

baemin_review_nos = {str(r['reviewNo']) for r in reviews}

all_data = []
deleted_count = 0
for row in ws.iter_rows(min_row=2, values_only=True):
    if not any(row):
        continue
    row_store = str(row[0] or '').strip()
    review_no = str(row[3] or '').strip()
    if row_store != store_name:
        all_data.append(list(row))
    elif review_no in baemin_review_nos:
        all_data.append(list(row))
    else:
        deleted_count += 1

existing    = {str(r[3]).strip() for r in all_data if str(r[0]).strip() == store_name and r[3]}
new_reviews = [r for r in reviews if str(r['reviewNo']) not in existing]

for r in new_reviews:
    all_data.append([store_name, r['date'], star_str(r['stars']), str(r['reviewNo']),
                     r['nickname'], r['menu'], r['reviewText']])

all_data.sort(key=lambda x: parse_date(x[1]), reverse=False)

for row in ws.iter_rows(min_row=2):
    for cell in row:
        cell.value = None

for i, row_data in enumerate(all_data, start=2):
    ws.row_dimensions[i].height = 40.0
    for j, val in enumerate(row_data, start=1):
        cell = ws.cell(row=i, column=j)
        if j == 4:
            cell.value = str(val)
            cell.number_format = FORMAT_TEXT
        else:
            cell.value = val
        cell.alignment = data_align
        cell.font = Font(bold=False)

buf_out = io.BytesIO()
wb.save(buf_out)

# 저장 시도 — 실패 시 /tmp/ 백업
try:
    with open(EXCEL_PATH, 'wb') as f:
        f.write(buf_out.getvalue())
    saved_to = EXCEL_PATH
    print(f'[OK] 엑셀 저장 완료: {EXCEL_PATH}', file=sys.stderr)
except Exception as e:
    backup = '/tmp/배민_저점수리뷰_backup.xlsx'
    with open(backup, 'wb') as f:
        f.write(buf_out.getvalue())
    saved_to = backup
    print(f'[WARN] 원본 저장 실패 ({e}), 백업 저장: {backup}', file=sys.stderr)

print(json.dumps({
    'new_count': len(new_reviews),
    'deleted_count': deleted_count,
    'new_reviews': new_reviews,
    'saved_to': saved_to
}, ensure_ascii=False))
ENDPY
```

Python 스크립트가 비정상 종료하면 → `[FAIL] 엑셀 저장 Step5: <stderr 내용>` 출력.
저장 성공 후 → `[OK] 엑셀 저장 완료 (신규 N건, 삭제 N건)` 출력.

## 트러블슈팅 빠른 참조

| 증상 | 원인 | 해결 |
|------|------|------|
| `Failed to fetch` / `NetworkError` / `timeout_10s` | 페이지가 fetch 차단 | 4-B(DOM 스크래핑)로 전환 |
| `error: "unknown_shape"` | API 응답 구조 변경 | 4-B로 전환 + keys 확인 |
| 날짜 필터 JS 클릭 실패 (`not_found`) | 셀렉터 변경 | `find()` 재탐색 후 ref 클릭 |
| 스크롤 후 `gained === 0` | Virtual scroll 종료 | 수집 완료, 결과 확인 진행 |
| `parseFailCount > 0` | SVG 색상 코드 변경 | SVG 구조 출력 → 색상값 수정 |
| "등록된 가게가 없어요" | 계정 불일치 | 올바른 계정으로 로그인 후 재시도 |
| Python stderr에 `[WARN] 원본 저장 실패` | 엑셀 잠금 등 | `/tmp/` 백업 파일 확인 |
